# cursorcloudagent

开发向虚拟工作区：文件树、Web 终端、任务管理、摄像头实时预览。

## 功能

- **文件树** — 浏览、编辑、保存工作区内的真实文件
- **Web 终端** — xterm.js + node-pty，工作目录限定在 `WORKSPACE_ROOT`
- **任务区** — SQLite 持久化，支持增删改查与完成状态
- **摄像头** — 浏览器实时预览（仅视频，无麦克风）

## 快速开始

```bash
npm install
npm run dev
```

- 前端开发服务器：http://127.0.0.1:5173
- 后端 API / 终端：http://127.0.0.1:3000

开发模式下 Vite 会将 `/api` 和 `/ws` 代理到后端。

## 生产部署

```bash
npm run build
SERVE_CLIENT=1 npm start
```

访问 http://127.0.0.1:3000

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `WORKSPACE_ROOT` | 当前工作目录 | 文件与终端的根路径 |
| `HOST` | `127.0.0.1` | 监听地址 |
| `PORT` | `3000` | 监听端口 |
| `ACCESS_TOKEN` | 空 | 可选访问令牌；设置后 API 与终端需携带 |
| `SERVE_CLIENT` | `0` | 设为 `1` 时由后端托管前端静态资源 |

## 安全说明

- 默认仅监听 `127.0.0.1`，适合本机使用
- 终端具有真实 shell 权限，请勿在未鉴权的情况下暴露到公网
- 局域网使用时建议设置 `ACCESS_TOKEN`，并在页面「访问令牌」中配置
